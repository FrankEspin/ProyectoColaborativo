Funcionalidad de Inicio de Sesion Consta de una serie de 7 pasos: -- Paso 1-- Acceder a la página web o descargar GithHub Desktop -- Paso 2 -- Crear la cuenta de GitHub, pondremos un correo, una contraseña y un nombre de usuario -- Paso 3 -- Verificacion de las credenciales, GitHub verifica las credenciales consultando a su base de datos -- Paso 4 -- Autenticación de dos factores -- Paso 5 -- Acceso Exitoso -- Paso 6 -- Recuperación de contraseña -- Paso 7 -- Sesion iniciada y cierre de sesión
